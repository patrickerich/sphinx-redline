Guest key tool

Encrypts a GitHub or GitLab token with a passphrase, for the redline_guest_key setting of sphinx-redline. Guests who know the passphrase can then comment on your documentation.

Everything happens in this page: the token and passphrase are not sent anywhere. The resulting key is published in every page of your site, so anyone can try to guess the passphrase offline. Use a long one, and a token that can only write to the comments repository.

A fine-grained GitHub token with Contents: read and write on the comments repository only, or a GitLab project access token with the api scope and the Developer role.

At least 16 characters. Share it with the people who may comment.

Put it in conf.py, for example redline_guest_key = os.environ.get("REDLINE_GUEST_KEY") with the key stored as a CI variable. It is safe to publish, as long as the passphrase is strong.
