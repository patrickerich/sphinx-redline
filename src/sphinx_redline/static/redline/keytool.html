Guest key tool

Fill in two things you already have, and this page makes the guest key that lets guests comment on your sphinx-redline site.

Where it comes fromWhat to do with it
Tokenyou fill in from GitHub or GitLabKeep it secret
Passphraseyou fill in you choose itGive it to the people who may comment
Guest keythis page makes it from the two abovePut it in your site's settings; safe to share

1 Your token you fill in

The token GitHub or GitLab gave you. On GitHub: a fine-grained token with Contents: read and write on the comments repository only. On GitLab: a project access token with the Developer role and the api scope.

2 Your passphrase you fill in

What commenters type to sign in; at least 16 characters. Renewing a token? Type your current passphrase, so commenters can keep using it.

No passphrase yet?

Write this passphrase down: commenters need it, and it cannot be recovered from the key.

3 Make the key

Your guest key made by this page

Put this key in your site's settings: the REDLINE_GUEST_KEY CI variable, read in conf.py as redline_guest_key = os.environ.get("REDLINE_GUEST_KEY"). The key is safe to share; the token and passphrase are not.

Is this safe?

Everything happens in this page: the token and passphrase are not sent anywhere. The key is published in every page of your site, so anyone can try to guess the passphrase offline. Use a long passphrase, and a token that can only write to the comments.
