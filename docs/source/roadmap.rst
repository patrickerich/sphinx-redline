Roadmap
=======

sphinx-redline is at an early stage and not usable yet. The planned order is
below; it may change as the work progresses.

#. **Done** — Package, test and documentation scaffold. The extension loads
   into Sphinx but does nothing yet.
#. **Next** — Source anchors: the build adds the source file, line and a
   stable identifier to each block in the HTML.
#. Comment file format, and a browser script that shows existing comments
   next to their text.
#. Guest passphrase sign-in and saving comments to GitHub and GitLab. At this
   point these docs get a live example comment and a "Try it on your fork"
   tutorial.
#. Re-anchoring comments when the source changes, and marking comments that
   cannot be placed as outdated.
#. Sign in with GitLab.
#. Sign in with GitHub (optional; needs a small login relay).
